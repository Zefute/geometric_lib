# geometric_lib

---
## Общее описание 

*geometric_lib** - библиотека на языке Python с функциями для вычесления плошади и периметра фигур: квадрата, круга, треугольника, прямоугольника.

все работы велись в ветке "new_feature_561621".

---
## Возможности


| Файл          | Функции                          |
|---------------|----------------------------------|
|`circle.py`    |`area(r)`,    `perimeter(r)`      |
|`rectangle.py` |`area(a, b)`, `perimeter(a, b)`   |
|`square.py`    |`area(a)`,    `perimeter(a)`      |
|`triangle.py`  |`area(a, h)`, `perimeter(a, b, c)`|


---
## Использование

```bash
git clone https://github.com/<ваш_логин>/geometric_lib
cd geometric_lib
python -c "import rectangle; print(rectangle.area(3, 4))"
```

## План тестирования (Лабораторная работа №4)

### 1. Цели и задачи тестирования
**Цель:** Проверка корректности работы математических функций библиотеки `geometric_lib`.  
**Задачи:**  
- Автоматизировать процесс проверки вычислительных алгоритмов.  
- Убедиться, что функции корректно обрабатывают стандартные входные данные (целые и дробные числа).  
- Проверить реакцию функций на граничные значения (например, ноль).  

### 2. Описание тестируемого продукта
`geometric_lib` — это библиотека на языке Python, предоставляющая набор функций для расчета площадей (`area`) и периметров (`perimeter`) четырех базовых геометрических фигур. Библиотека не имеет внешних зависимостей (кроме стандартного модуля `math`).

### 3. Область тестирования
Тестированию подлежат следующие модули и функции:  
- `rectangle.py`: `area(a, b)`, `perimeter(a, b)`  
- `square.py`: `area(a)`, `perimeter(a)`  
- `triangle.py`: `area(a, h)`, `perimeter(a, b, c)`  
- `circle.py`: `area(r)`, `perimeter(r)`  

### 4. Стратегия тестирования
- **Тип тестирования:** Функциональное модульное тестирование (Unit-Testing).  
- **Инструментарий:** Встроенный фреймворк Python `unittest`.  
- **Методы:** Тестирование на основе требований (формулы геометрии).  
- **Техники формирования данных:**  
  - *Граничные значения:* передача нуля в качестве параметров (площадь должна быть равна 0).  
  - *Классы эквивалентности:* проверка на целых положительных числах и числах с плавающей точкой (`float`).  
  - *Специфика:* для круга используется метод `assertAlmostEqual` из-за особенностей вычислений с иррациональным числом $\pi$.

### 5. Критерии приемки
- Все написанные unit-тесты успешно проходят (статус `OK`).  
- Отсутствие ошибок `AssertionError` при сравнении ожидаемых и фактических результатов.  
- Код тестов успешно интегрирован в репозиторий и доступен для запуска.

### 6. Ожидаемые результаты
- Сформирован набор автоматизированных тестов, покрывающий базовые сценарии использования библиотеки.  
- При внесении изменений в основные файлы разработчик сможет быстро убедиться в отсутствии регрессионных ошибок с помощью запуска `python3 -m unittest discover`.
